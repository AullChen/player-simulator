# 概率与生涯模型

## 目标

随机模式同时追求两件事：

1. 有公开资料的字段使用可追溯的校准值；
2. 组合结果保持足球逻辑一致，例如门将通常更高、中锋进球率高于中后卫、
   巅峰能力会影响国家队履历、身价与荣誉。

因此生成器不是把所有字段独立摇号，而是先抽身份与位置，再通过条件规则生成职业结果。
来源、样本范围和限制见[公开数据来源](public-data-sources.md)。

## 当前转盘顺序

```text
成长协会（按职业球员注册人数）
        ↓
国籍所属洲足联 → 洲内具体国家 / 位置 / 惯用脚
        ↓
出生信息 / 公民身份 / 身高体重 / 号码 / 生涯长度
        ↓
个人能力与风格
        ↓
俱乐部线：青训 → 首秀 → 逐次转会、价格、合同、伤病和赛事数据
        ↓
国家队线：入选 → 首秀 → 出场、进球、世界杯和洲际赛事
        ↓
冠军 / 个人荣誉 / 最终完整档案
```

基础加权表位于 `lib/data/football_catalog.dart`，公开来源元数据位于
`lib/data/probability_sources.dart`，条件生成逻辑位于
`lib/services/random_career_generator.dart`。

转盘组件不把项目画成等分扇区。任一项目的角度为：

```text
扇区角度 = 项目权重 ÷ 当前转盘总权重 × 360°
```

例如英格兰协会的职业球员人数为 5,582，全球总数为 128,694，因此当前协会转盘中的
英格兰扇区为 `5,582 ÷ 128,694 = 4.34%`。

## 公开数据校准

### 成长协会与国籍

FIFA Professional Football Report 2023 报告全球 128,694 名男子职业球员。
报告逐洲列出的 27 个主要协会人数直接组成协会转盘；其合计为 65,702，其余
62,992 人放入“其他 FIFA 协会”尾部桶，保证总数精确闭合。

协会人数不是国籍。国籍独立使用 FIFA Club World Cup 2025 官方名单公布的完整
81 国计数：先把具体国家人数按 AFC、CAF、Concacaf、CONMEBOL、OFC、UEFA 汇总形成
第一个转盘，再只在命中的洲足联名单中绘制第二个国家转盘。两层扇区都保留公开人数比例，
因此最终结果一定是具体国家，不再出现“其他国家”。

这仍然是 32 支洲际代表俱乐部的精英样本，不是全球职业球员国籍概率；
界面与文档必须保留“世俱杯精英样本”口径。

### 国际转会

FIFA 2025 年 1 月快照给出男子职业国际转会平均年龄 24.9 岁，以及 17.7% 涉及费用。
生成器以 24.9 岁为中心，用三个均匀随机数之和近似钟形分布，并将结果限制在首秀与退役年龄之间。

转会类型权重为：

| 类型 | 权重 | 性质 |
| --- | ---: | --- |
| 自由转会 | 62 | 根据“占多数”的公开关系完成建模 |
| 租借 | 20 | 根据剩余类型关系完成建模 |
| 永久转会 | 18 | 对齐 17.7% 有偿国际转会的公开值 |

这些概率只应解释为“按 FIFA 国际转会口径校准”，不能推广到同一协会内部的全部转会。

## 条件模型

- 出生年份由退役年份和退役年龄反推，完整生涯结束年份不会晚于当前年份。
- 青训入营年龄必须早于职业首秀；每次转会年龄必须递增且位于首秀和退役之间。
- “加盟当前俱乐部”和“当前合同开始”是两个字段：零转会时前者等于首秀年份，后者可以是续约年份。
- 合同开始不得早于加盟，合同结束等于完整生涯的退役年份。
- 位置决定身高区间、体重基线、号码池、进球率、助攻率、牌率和门将零封。
- 青训等级影响初始能力，但不锁死上限；成长曲线保留罕见的长尾突破。
- 巅峰能力先按游戏目标抽取分段：80+ 为 50%、70–79 为 40%、70 以下为 10%。
  随后在命中分段内，按原青训初始值与成长幅度联合分布做条件抽样，因此分段内相对概率不变。
- 随机与模拟人生共用 `PeakRatingDistribution`，避免两套逻辑随版本漂移。模拟人生提高初始属性，
  并把正向行动增量放大为 1.6 倍；最终巅峰总评仍严格留在先抽中的分段内。
- 能力、年龄和位置共同决定比赛时间、国家队履历与模拟转会费。
- 身价按年龄和能力生成并在 29 岁后衰减，明确标记为模拟值。
- 分赛事数据从生涯总计拆分，测试保证出场、进球和助攻重新汇总后等于总数。
- 结构化转会费重新汇总后必须等于档案中的累计转会费。

## 模拟球员的选择密度

用户可以选择五档生涯节点：

| 密度 | 年龄节点 | 数量 |
| --- | --- | ---: |
| 随机长度 | 17 岁开始；每次选择后才决定是否生成下一节点，最迟 60 岁 | 不预设 |
| 关键节点 | 15、19、24、29、34 | 5 |
| 每 3 年 | 15、18、21、24、27、30、33、36 | 8 |
| 每 2 年 | 15、17、19、21、23、25、27、29、31、33、35 | 11 |
| 逐年选择 | 15–36 岁每年 | 22 |

每个年龄节点根据年龄映射到青训、上升、巅峰或老将阶段。每个阶段有 20 个场景母题，
每个场景和对应类别的 5 个行动策略组合成 100 个原始候选。引擎随后：

1. 根据人物属性最低/最高要求过滤不可能选项；
2. 根据技术短板、声望、纪律、训练负荷、健康和伤病风险抽取一个事件类别；
3. 在该类别中选择一个不与上轮重复的背景，再不放回抽取 3–5 个同类行动；
4. 应用选择带来的属性、训练负荷、伤病风险和转会变化；
5. 用更新后的状态生成下一节点。

随机长度模式不创建年龄表或节点总数。引擎只创建 17 岁的首个节点；玩家选定行动后，
先独立抽取极低概率的场外严重意外，再使用该选项自己的退役概率判断足球生涯是否继续。
若继续，才向时间线追加 1–2 个赛季后的下一个节点。

年龄提供基础风险，健康缺口、训练负荷、既往伤病、冒险复出和低合同竞争力增加风险，
主动恢复会降低风险。命中后再抽取急性重伤、慢性伤病、无合适俱乐部、高龄或个人原因。
所有年龄的继续概率都大于零；60 岁完成当轮选择后强制自然退役。原因权重、意外代理值和
极端年龄个案的适用限制见[公开数据来源](public-data-sources.md)。

为避免开放生涯在球员尚未进入常见退役区间时过早集中结束，30 岁前先使用更低的分年龄
基础值，再把伤病、负荷和行动修正后的足球原因总风险乘以 `0.48`。该青年延续系数依据
公开职业长度关系做产品校准，不是论文发布的逐年龄精确退役率；极低概率场外意外不参与缩放。

FIFPRO 只描述幸运球员通常在三十岁出头退役，没有发布单一全球平均值。模型以 33 岁作为
明确的产品参考年龄：超过该年龄后，伤病或合同类别可按年龄、健康和伤病史抽出主动退役行动。
它是玩家可见且自行选择的确定性行动，不替代开放模式中独立的随机意外与足球原因退役抽签。

引擎会把每次选择后的隐藏模型记录为检查点，再从首秀到退役生成逐年快照。快照包括俱乐部、
队内角色、综合趋势、技术、身体、心智、竞技状态、士气、声望和关键事件提供给故事提示词。
玩家界面只显示综合总评及最近一次选择造成的总评变化，不显示其余人物属性。

每次非主动退役选择还会立即进行三类冠军抽签：

```text
国内联赛 = 俱乐部层级 + 当前总评 + 声望 + 比赛行动 - 当季伤病
国内杯赛 = 俱乐部层级 + 当前总评 + 比赛行动 - 当季伤病
洲际赛事 = 洲足联赛事 + 俱乐部层级 + 当前总评 + 比赛行动 - 当季伤病
```

命中后保存“年龄 · 完整赛季 · 当时俱乐部 · 具体赛事冠军”。同一俱乐部、同一赛季和
同一赛事不会重复入档；结算阶段不再根据最终声望推算一个泛化冠军数量。

因此更密的模式确实包含更多可塑造人物的机会，同时也承担更多伤病和负面事件风险，
而不是旧版的固定属性归一化。详细策划接口见[人生事件设计](life-event-design.md)。

人物模型的分项数值仍属于隐藏状态。玩家只看到总评、节点之间已经发生的赛季叙事、
当前俱乐部、事件类别、每个候选处境和可执行的选择，不看到属性值、门槛或候选池筛选数量。

## 仍需生产数据支持的项目

位置、惯用脚、伤病、青训、合同和全球国籍等概率仍需覆盖范围一致且授权明确的数据集。
正式升级时应：

- 固定赛季、联赛范围和“在册/出场/分钟加权”口径；
- 记录缺失值、双国籍、租借、自由转会和退役球员的处理；
- 将概率表改为带版本的数据包并检查外键；
- 运行至少一万次蒙特卡洛抽样，对输出分布做区间回归；
- 保留固定种子快照，确保版本更新可解释。

当前自动化测试适合产品回归，不等同于对全球职业球员总体的统计证明。
