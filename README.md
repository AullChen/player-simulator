# 球员模拟器

一个基于 Flutter 的足球职业生涯模拟器。用户可以把概率、关键选择或自定义数据转换成完整球员档案，并调用自有故事 API 生成中文生涯故事。

## 已实现模式

### 全随机 · 真实概率

- 用五次转盘抽取逐步揭示国籍、惯用脚、身高、位置、青训和完整生涯。
- 主要国籍和国际转会概率由 FIFA 公开资料校准，并记录数据版本、样本范围和限制。
- 生成出生与公民身份、身体和号码、注册合同、经纪人、俱乐部与国家队履历。
- 生成结构化转会/伤病/模拟身价轨迹，以及分赛事出场、首发、分钟、进球、助攻和纪律数据。
- 支持固定随机种子测试，保证概率引擎可复现。

### 模拟球员 · 生涯选择

- 用户只指定国籍和位置。
- 可选 5 个关键节点、每 3 年 8 个节点、每 2 年 11 个节点或 15–36 岁逐年 22 个节点。
- 逐年事件覆盖青训、首秀、合同、外租、战术、转会、国家队、负荷、伤病、领导力和退役。
- 能力、声望和稳定性按“等效 5 次选择”归一化，选择更密不会天然获得更多属性。

### 梦想球员 · 自由创作

- 可填写身份与身体、位置号码、青训能力、俱乐部合同、经纪人和国家队信息。
- 可逐行录入转会、伤病、身价和分赛事统计，并填写完整比赛、纪律、冠军和个人荣誉数据。
- 俱乐部列表会自动转换为生涯时间轴。

## 运行

环境要求：Flutter 3.32 或兼容 Dart 3.8 的 Flutter 版本。

```powershell
flutter pub get
flutter run
```

项目没有第三方运行时依赖，可在 Flutter SDK 与 Pub 缓存完整的环境中离线解析。

## 接入故事 API

未配置 API 时，结果页使用本地示例生成器，方便完整演示。配置后，应用会在球员档案生成完成时自动调用远程接口：

```powershell
flutter run `
  --dart-define=STORY_API_URL=https://api.example.com/player-story `
  --dart-define=STORY_API_TOKEN=your-token
```

请求方式为 `POST`，请求体结构如下：

```json
{
  "task": "generate_football_player_story",
  "language": "zh-CN",
  "player": {
    "mode": "random",
    "personal_information": {},
    "registration_and_contract": {},
    "national_team": {},
    "ability": {},
    "career_information": {}
  }
}
```

服务端响应可使用以下任一结构：

```json
{"story": "生成的故事"}
```

也兼容顶层 `text`、`content`，或 `data.story`。非 2xx 响应和缺少故事字段都会在结果页显示可重试错误。

> `--dart-define` 的值会进入客户端构建产物，不应被当作安全的密钥存储。生产环境应让 `STORY_API_URL` 指向自己的后端代理，由后端持有模型供应商密钥、执行鉴权和限流。Web 端还需要接口允许对应来源的 CORS 请求。

## 真实概率说明

当前版本使用“公开数据校准 + 显式产品建模”。FIFA Club World Cup 2025 名单用于校准精英球员国籍权重；FIFA 2025 年 1 月国际转会快照用于校准 24.9 岁平均转会年龄和 17.7% 有偿转会比例。Transfermarkt 公开资料页仅用于确定常见球员字段类型，不抓取其数据库，也不复刻其专有估值。

由于公开来源的样本范围不同，项目明确区分精确公开值、派生权重与产品建模值。正式上线前仍应接入有授权、带版本且覆盖口径一致的数据集，并记录：

- 数据来源、采样时间和覆盖联赛；
- 在册球员、出场球员还是分钟数加权的统计口径；
- 缺失值、双国籍、租借、自由转会和退役球员的处理方法；
- 每次概率表更新的版本与回归结果。

详细方法见[概率模型说明](docs/probability-model.md)和[公开数据来源](docs/public-data-sources.md)。

## 项目结构

```text
lib/
├── data/       # 足球目录与概率表
├── domain/     # 球员档案、职业章节、统计模型
├── screens/    # 三种模式、首页和结果档案
├── services/   # 随机引擎、生涯选择引擎、故事 API
├── theme/      # 颜色、排版和组件主题
└── widgets/    # 转盘与通用展示组件
```
